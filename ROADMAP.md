# Graphics Programmer: программа чтения и практики

Версия 4 · 25 октября 2026. Номера относятся к указанным изданиям. Названия тем сокращены; это индивидуальная подборка, не полные оглавления.

## Как пользоваться

Первый проход — этапы 00–08. Затем системная глубина и одна–две специализации. Уже знакомый этап можно закрыть своим кодом и проверками, без повторного чтения. Основной проект — 3D Viewer; нужные приёмы применяй в LUX//PRISM. Начатый Vulkan можно продолжать отдельными короткими сессиями.

Время у чтения — размер **одного подхода**, не срок прохождения всех перечисленных глав. На подход: один подраздел, схема, 3–5 тезисов. Основное чтение ведёт этап; альтернативы открываются при пробеле. Большой диапазон разбивается на несколько подходов.

Пример сессии: 5 минут — вопрос, 30–50 — чтение, 60–120 — свой эксперимент, 10 — объяснение без книги. В короткий день: 10 минут повторения, 20 чтения, 25 эксперимента, 5 заметки.

Прочитанная глава и освоенный навык учитываются отдельно. Этап считается подтверждённым после практики и всех критериев. Экспертность требует разных проектов, измерений и обратной связи; завершение списка само по себе её не гарантирует.

## 00. Сверить стартовую точку

Начать с реального пробела. У тебя уже есть tinyrenderer и опыт WebGPU; знакомое можно подтвердить демонстрацией.

**Предпосылки:** нет.

**Темы:** Сборка, треугольник, камера, ресурсы, диагностика.

### Что читать

- [ ] **Real-Time Rendering — Гл. 2–3: конвейер и GPU, обзор** (4-е издание, 2018). Основное. Подход ~30 мин. Пролистай знакомое; запиши только 3 непонятных механизма. Не перечитывай всё ради галочки. [Источник / оглавление](https://www.realtimerendering.com/).

**Результат в коде:** Собери viewer и создай заметку: умею / не понимаю / хочу проверить. Сохрани один корректный кадр и способ его повторить.

### Проверка

- [ ] Могу показать путь CPU → draw → изображение.
- [ ] Объясняю назначение vertex/index buffer, bind group и render target.
- [ ] Выбрал одну ближайшую функцию viewer и способ проверить её.
- [ ] Практический результат готов и воспроизводим.

**Моя заметка:** commit / тестовая сцена / измерения / что пока не понимаю.

## 01. Научиться думать функциями

Предсказывать изображение по формуле и строить свою формулу по изображению.

**Предпосылки:** audit.

**Темы:** step, smoothstep, mix, UV, маски, SDF, композиция.

### Что читать

- [ ] **The Book of Shaders — Гл. 05: shaping functions** (Опубликованные веб-главы 05–13). Основное. Подход ~40 мин. Сначала plot и smoothstep. После каждого примера меняй один параметр и предсказывай результат. [Источник / оглавление](https://thebookofshaders.com/05/).
- [ ] **The Book of Shaders — Гл. 06–07: цвет и формы** (Опубликованные веб-главы 05–13). Основное. Подход ~50 мин. В 06 разберись с независимыми RGB-коэффициентами; в 07 — пересечение и объединение масок. [Источник / оглавление](https://thebookofshaders.com/07/).
- [ ] **The Book of Shaders — Гл. 08–09: преобразования и узоры** (Опубликованные веб-главы 05–13). Основное. Подход ~45 мин. Сдвиг/поворот координат, fract, повторение ячеек. Порядок преобразований проверяй картинкой. [Источник / оглавление](https://thebookofshaders.com/08/).
- [ ] **The Book of Shaders — Гл. 10–13: random, noise, cellular, fBm** (Опубликованные веб-главы 05–13). Углубление. Подход ~60 мин. После своих масок. Сделай один осмысленный эффект для LUX//PRISM; не пытайся выучить все noise-функции. [Источник / оглавление](https://thebookofshaders.com/11/).

**Результат в коде:** Без готового шейдера собери композицию из 4 прямоугольников, круга и светящейся линии. Затем перенеси математику в WGSL.

### Проверка

- [ ] Могу по графику написать порог, полосу и плавный переход.
- [ ] Объясняю отдельно цвет и маску, а также покомпонентный mix.
- [ ] Фигуры сохраняют пропорции при изменении окна.
- [ ] Практический результат готов и воспроизводим.

По 1–2 подраздела за подход. [Источник / оглавление](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).

[Источник / оглавление](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).

- [ ] **Real-Time Collision Detection — §3.4–3.6; в гл. 5 — пересечения луча с плоскостью и треугольником** (Ericson, 2005). Альтернатива / справочник. Подход ~40 мин. ## 03. Сцена: mesh, submesh, material

Разделить геометрию, экземпляр объекта и материал, затем загрузить небольшую glTF-сцену.

**Предпосылки:** math.

**Темы:** Vertex/index ranges, glTF primitive, node hierarchy, accessors, texture semantics.

### Что читать

- [ ] **Fundamentals of Computer Graphics — §12.1–12.2** (5-е издание, 2021). Основное. Подход ~40 мин. Меши и граф сцены. Нарисуй структуры данных до реализации. [Источник / оглавление](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).
- [ ] **Khronos glTF Tutorial — Разделы 4–5, 8–10, 12** (glTF 2.0). Основное. Подход ~50 мин. Порядок: узлы → buffers/accessors → meshes/primitives → материалы → textures/images/samplers. Читай по одному разделу и проверяй на простом файле. [Источник / оглавление](https://github.khronos.org/glTF-Tutorials/gltfTutorial/).
- [ ] **Game Engine Architecture — §7.2: управление ресурсами** (Нумерация для 3-го издания, 2018). Альтернатива / справочник. Подход ~35 мин. По необходимости: handles, кэш и жизненный цикл. Не вводи asset pipeline до первого корректного импорта. [Источник / оглавление](https://www.gameenginebook.com/toc.html).

**Результат в коде:** Один mesh с двумя материалами; два экземпляра общей геометрии; parent-child transform. Загрузчик должен корректно сообщать об отсутствующем ресурсе.

### Проверка

- [ ] Знаю, какие данные общие, а какие принадлежат экземпляру.
- [ ] Правильно учитываю offsets, stride, component type и границы индексов.
- [ ] Материал выбирается для primitive/submesh, world transform — для узла.
- [ ] Практический результат готов и воспроизводим.

## 04. Текстуры, sampling и прозрачность

**Предпосылки:** scene.

**Темы:** Дискретизация, convolution, reconstruction, mip/LOD, derivatives, alpha.

### Что читать

- [ ] **Fundamentals of Computer Graphics — Гл. 3; гл. 10; §11.1–11.4** (5-е издание, 2021). Основное. Подход ~60 мин. Сначала пиксель и alpha, затем фильтрация и sampling, затем текстурные выборки. Гл. 10 раздели на несколько сессий. [Источник / оглавление](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).
- [ ] **Real-Time Rendering — §6.1–6.2; §6.7: текстурный конвейер, фильтрация и bump mapping** (4-е издание, 2018). Альтернатива / справочник. Подход ~45 мин. Используй как справочник после эксперимента с FCG. Уточни роль производных и цветовых форматов. [Источник / оглавление](https://www.realtimerendering.com/).

**Результат в коде:** Сцена с наклонной шахматной плоскостью: nearest/linear/mips; отдельный тест straight/premultiplied alpha.

## 05. Свет, цвет и простое освещение

Получать предсказуемый свет в linear space и понимать единицы величин.

**Предпосылки:** sampling.

**Темы:** Radiance/irradiance, BRDF-интуиция, N·L, sRGB, HDR, exposure.

### Что читать

- [ ] **Fundamentals of Computer Graphics — Гл. 5: базовое освещение поверхности** (5-е издание, 2021). Основное. Подход ~40 мин. Реализуй Lambert и один specular-вариант. Ambient constant пометь как приближение. [Источник / оглавление](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).
- [ ] **Real-Time Rendering — §8.1–8.2: величины света и путь к экрану** (4-е издание, 2018). Основное. Подход ~50 мин. На первом проходе: radiometry, radiance/irradiance, color spaces и преобразование для экрана. [Источник / оглавление](https://www.realtimerendering.com/).
- [ ] **Physically Based Rendering — §4.1–4.3** (4-е издание, онлайн). Углубление. Подход ~50 мин. Углубление единиц и поверхностного отражения. Нарисуй поток света через поверхность и телесный угол. [Источник / оглавление](https://www.pbr-book.org/4ed/contents).

**Результат в коде:** Directional + point light; normal/albedo/depth debug views; HDR-буфер и явное преобразование для вывода.

## 06. Материалы и PBR

### Что читать

- [ ] **Real-Time Rendering — §9.1, 9.3–9.8: физика света, BRDF, Fresnel и microfacet** (4-е издание, 2018). Основное. Подход ~60 мин. Читай порциями: BRDF → Fresnel → microfacet → материальные параметры. После каждой части обновляй тестовую сцену. [Источник / оглавление](https://www.realtimerendering.com/).
- [ ] **Filament: Physically Based Rendering — Раздел Material system: diffuse, specular, parameterization** (Технический документ проекта). Альтернатива / справочник. Подход ~45 мин. Проверь определения roughness и распределение энергии. Не смешивай формулы из разных моделей без объяснения. [Источник / оглавление](https://google.github.io/filament/Filament.md.html).
- [ ] **Foundations of Game Engine Development, Vol. 2 — §7.5–7.6: tangent space и normal mapping** (Rendering, 2019; главы начинаются с 5). Альтернатива / справочник. Подход ~45 мин. Дополнительное подробное объяснение TBN; практикуй на UV-швах и отражённых координатах. [Источник / оглавление](https://foundationsofgameenginedev.com/).

**Результат в коде:** Матрица сфер по roughness/metallic, normal mapping и раздельный просмотр diffuse/specular.

## 09. C++ и данные под нагрузкой

Владеть временем жизни и объяснять цену CPU-кода. Можно проходить параллельно этапам света, по 1 сессии в неделю.

### Что читать

- [ ] **Effective Modern C++ — Правила 17–21, 23, 25, 29** (Meyers, 42 правила, C++11/14). Основное. Подход ~35 мин. Special members → ownership → move. Одно правило и один компилируемый эксперимент за раз. [Источник / оглавление](https://www.oreilly.com/library/view/effective-modern-c/9781491908419/).
- [ ] **Computer Systems: A Programmer’s Perspective — §2.4; гл. 5; §6.2–6.6** (3-е издание). Основное. Подход ~60 мин. Float, оптимизация и кэш. К главам возвращайся при конкретном bottleneck. [Источник / оглавление](https://csapp.cs.cmu.edu/3e/pieces/preface3e.pdf).
- [ ] **A Tour of C++ — §1.5; гл. 3–6; гл. 12** (3-е издание, 2022). Альтернатива / справочник. Подход ~40 мин. Ревизия lifetime, модульности, ошибок, классов/операций и контейнеров. Только незнакомое. [Источник / оглавление](https://www.stroustrup.com/tour3toc.pdf).

Сначала простой контейнер; затем изменение layout. [Источник / оглавление](https://www.dataorienteddesign.com/dodbook/).

**Результат в коде:** Проверь ownership GPU-ресурсов; измерь обход AoS и SoA на реальных render items. Сохрани методику и результаты.

## Издания и отложенное чтение

### Fundamentals of Computer Graphics — 5-е издание, 2021

Основной учебник фундамента. Читай порциями под задачу; знакомые разделы проходи через проверку.

**Отложить:** На первом проходе отложи гл. 15, 17, 19–23; 13–14 понадобятся к Monte Carlo. Старый OpenGL из гл. 17 не нужно переносить построчно.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://www.routledge.com/Fundamentals-of-Computer-Graphics-Fifth-Edition/Shirley-Marschner/p/book/9780367505035).

### Real-Time Rendering — 4-е издание, 2018

Главная карта real-time rendering после базового опыта. Нужные разделы перечитываются при реализации.

**Отложить:** Не нужно подряд читать всю книгу. 13–17 и 21 — по специализации. Современные API и исследования сверяй с текущими первоисточниками.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://www.realtimerendering.com/).

### 3D Math Primer for Graphics and Game Development — 2-е издание / веб-версия авторов

Подробное объяснение математики, если FCG слишком сжат. Можно заменить им математическое чтение FCG.

**Отложить:** Не дублируй весь материал двух учебников. Главы 11–12 о механике не обязательны для первых rendering-задач.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://gamemath.com/book/).

### Game Engine Architecture — Нумерация для 3-го издания, 2018

Выборочные главы об устройстве систем. Сопоставляй с текущим проектом.

**Отложить:** Полный универсальный движок не является предварительным условием игры. В 4-м издании нумерация меняется: анимация — гл. 13, а в 3-м — гл. 12.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://www.gameenginebook.com/toc.html).

### Real-Time Collision Detection — Ericson, 2005

Справочник геометрии, пересечений и устойчивости вычислений.

**Отложить:** Полный physics engine, GJK/EPA и continuous collision detection — по задаче; для рендера сначала AABB, плоскости, лучи, BVH.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://realtimecollisiondetection.net/books/rtcd/toc/).

### Physically Based Rendering — 4-е издание, онлайн

Глубокая теория света, выборки и light transport; после первого real-time renderer.

**Отложить:** Не начинай с воспроизведения всей архитектуры pbrt. Спектральный рендеринг, волосы, сложные среды и GPU wavefront — последующие специализации.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://www.pbr-book.org/4ed/contents).

### Computer Systems: A Programmer’s Perspective — 3-е издание

CPU, представление чисел, память и измеряемая оптимизация.

**Отложить:** Y86 из гл. 4 и сети из гл. 11 не обязательны на первом проходе. Номера страниц зависят от издания; используй номера разделов.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://csapp.cs.cmu.edu/3e/pieces/preface3e.pdf).

### Effective Modern C++ — Meyers, 42 правила, C++11/14

Короткие независимые правила с обязательным маленьким примером.

**Отложить:** Книга не покрывает весь C++20. Детали универсальных ссылок нужны при написании generic-кода, а не до первого кадра.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://www.oreilly.com/library/view/effective-modern-c/9781491908419/).

### Programming Massively Parallel Processors — Нумерация для 4-го издания, 2022

Основы GPU и parallel patterns. На твоём AMD переноси идеи в WGSL/compute или HIP.

**Отложить:** CUDA-примеры не запускаются напрямую на AMD. Номера ниже относятся к 4-му изданию; у 5-го часть поздних глав другая. MRI и deep learning сейчас не нужны.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://shop.elsevier.com/books/programming-massively-parallel-processors/hwu/978-0-323-91231-0).

### Operating Systems: Three Easy Pieces — Веб-версия 1.10

ОС для понимания адресного пространства, потоков и синхронизации.

**Отложить:** Файловые системы и безопасность — отдельный интерес. Не делай весь курс ОС условием начала рендеринга.

Оглавление / официальный материал сверены 25.10.2026. [Источник](https://pages.cs.wisc.edu/~remzi/OSTEP/).

### Game Programming Patterns — Бесплатная веб-версия автора

Компактные главы о цикле игры, локальности и потоках данных.

**Отложить:** Не внедряй каждый паттерн. Читай с вопросом: какую конкретную проблему он решит в моём коде?

Главы указаны по названию; номера не используются. [Источник](https://gameprogrammingpatterns.com/contents.html).

### The Book of Shaders — Опубликованные веб-главы 05–13
