# Graphics Programmer Roadmap — подробная программа v6

> 21 тематический блок, 116 коротких уроков. Дерево из 57 узлов осталось прежним; навыки засчитываются по конкретным проверенным урокам.

## Как пользоваться программой

1. Открой «Сегодня»: там автоматически выбран первый незавершённый урок активного блока.
2. Возьми один небольшой указанный фрагмент книги либо документации; знакомое можно не перечитывать.
3. Сделай эксперимент **самостоятельно**. Зафиксируй проверку: код, тест, скриншот, commit или измерение.
4. Поставь галочки «Могу объяснить» и «Реализовал, проверил». Только обе вместе закрывают урок.
5. В дереве навык получает «Готово» автоматически, **когда все назначенные ему уроки подтверждены**. Одного прочтения книги недостаточно.
6. Отмечай в «Точке возврата» следующий маленький шаг; один урок может занимать несколько дней.

Параллельно можно развивать игру LUX//PRISM и Vulkan Lab, но не стоит превращать их в обязательные предварительные условия для основного 3D Viewer.

## Как дерево связано с уроками

У каждого узла дерева есть набор определённых уроков. Автоматическое «Готово» появляется только при выполнении **каждого** урока из этого набора (включая понимание и практику). Если ранее узел был помечен вручную, статус сохраняется; при этом в программе можно независимо подтвердить каждый соответствующий урок. Отмена автоматического статуса предлагает снять практическое подтверждение и оставляет заметки.

Ветки `sylvune` и `apply` остались ручными: в текущем основном плане для них нет обязательных уроков.

## Источники и ограничения

Номера глав привязаны к конкретным изданиям и тематическим оглавлениям, указанным в карте. Иногда написано «раздел по теме» — это сделано намеренно, чтобы не выдавать приблизительный номер подраздела за точный. Книги, исходная полка из 174 материалов и карточки коротких занятий сохранены.

Если ты меняешь браузер или домен, экспортируй прогресс в JSON и импортируй на новом адресе.
