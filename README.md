# Graphics Programmer Roadmap v7

Открой **[index.html](index.html)** в браузере. Сборка и сервер не нужны. Для GitHub Pages публикуй весь репозиторий: приложение использует `data/*.js`, `app-v7.js` и `roadmap-v7.css`.

Маршрут подготовки к работе graphics / rendering programmer: **44 блока, 233 урока, 7 входных испытаний и 8 проектов с техническими заданиями**. В основе — C++, математика, один API (D3D12 либо Vulkan), GPU, корректность изображения, диагностика и производительность. Прежние книги и 116 уроков сохранены; добавлены официальные источники и доклады.

## С чего начать

1. **Старт:** выбери API и пройди испытания по знакомым темам. Подтверждение относится к одному блоку; отдельные уроки сохраняют свои отметки.
2. **Программа:** иди по шести этапам и предпосылкам. По умолчанию показаны ядро и твой API. Старые игровые и вводные задания доступны в дополнительных блоках.
3. **Дерево:** смотри зависимости между блоками. Прежняя карта v6 доступна отдельной кнопкой.
4. **Сегодня:** работай над одним экспериментом. Для завершения урока нужны понимание и проверенная реализация. Сохраняй commit, команду запуска, capture или результат в заметках.
5. **Проекты:** выбери основной renderer и одну работу в глубину. Внутри — минимум, критерии сильной версии, общее качество, необязательные расширения и сценарий демонстрации.
6. **Готовность:** проверь ориентиры для откликов и тренировку интервью. UE, ray tracing, GI, screen-space и volumetrics — специализации, проходить их все не требуется.

Полный маршрут, уроки, источники и технические задания доступны в **[ROADMAP.md](ROADMAP.md)**. Оценки времени приблизительны; часы уроков и проектов пересекаются, потому что практику можно выполнять в одном renderer.

## Что изменилось

- Основной путь переориентирован с WebGPU Viewer и игры на C++ / D3D12 либо Vulkan. WebGPU и LUX//PRISM сохранены как дополнительные занятия.
- Добавлены отдельные блоки GPU architecture, resource lifetime, shader toolchain, synchronization, frame debugging, IBL, CSM, compute, clustered lighting, TAA, GPU-driven rendering, render graph, CPU jobs/streaming и shipping.
- Знакомая база подтверждается входными задачами с критериями и evidence. Массовых отметок уроков за одно прочтение нет.
- Восемь проектов имеют самостоятельные рубрики и сохраняемые отметки. Приложение хранит самооценку и не проверяет код автоматически.
- Источники требований разделены: официальные публикации Ubisoft и вторичная senior-вакансия Saber. Это ориентиры, не обещание открытой позиции или оффера.

## Прогресс и обновление

Перед обновлением экспортируй JSON. Данные хранятся в `localStorage` браузера, не в облаке. На прежнем URL v6 прогресс загружается по тем же ключам и идентификаторам. Сохраняются дерево v6, библиотека, заметки и уроки. Новые блоки не получают подтверждения за старые крупные этапы.

Экспорт **v7** включает старый прогресс, выбранный API, входные испытания и проекты. Импорт **v6/v7** объединяет записи; при совпадении записи импортируемая версия имеет приоритет. На другом URL/браузере используй импорт. Для `file://` и приватного режима поведение localStorage зависит от браузера — сохраняй резервный JSON.

## Разработка и проверка

Приложению Node.js не нужен. Эти команды предназначены только для разработки:

```sh
npm ci
npm test
npm run test:browser
npm run docs
```

Браузерная проверка использует установленный Chrome через Playwright. Для другого поддерживаемого браузера задай `BROWSER_CHANNEL`, например `msedge`. Проверяются навигация, зависимости, оба API, испытания, проекты, сохранение, импорт/экспорт v6/v7, экранирование заметок, мобильный экран и прежняя карта.

- `data/legacy-curriculum.js` — исходные уроки v6 со стабильными ID.
- `data/curriculum.js` — новые блоки, источники, ветки и входные испытания.
- `data/projects.js` — рубрики проектов и ориентиры готовности.
- `app-v7.js` / `roadmap-v7.css` — новый интерфейс поверх существующей библиотеки и уроков.
- `scripts/export-roadmap.mjs` — генерация Markdown из тех же данных.

После изменения учебных данных выполни `npm test` и `npm run docs`, чтобы сайт и Markdown оставались согласованы.
