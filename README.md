# Graphics Programmer Roadmap — карта знаний v9

Открой **[index.html](index.html)**. Сервер и сборка для работы сайта не нужны. Основное направление — **Vulkan Renderer / 3D Viewer на C++20**, с intermediate до advanced. WebGPU и повторение C++ не являются обязательным входом.

## Как пользоваться

- **Дерево** — главный экран: 15 направлений → разделы → 207 отдельных тем. Направления сворачиваются; есть фокус, поиск по понятиям и источникам, фильтры, zoom и перетаскивание. «Предпосылки на карте» показывает только выбранную тему и её обязательных предшественников.
- **Мой путь** — вычисляемый маршрут к viewer, PBR, GPU-driven, архитектуре, RT/GI или temporal rendering. Можно выбрать несколько целей или построить путь к одной теме. Порядок разделов не создаёт зависимостей.
- **Сегодня** — одна тема и одно действие: небольшой фрагмент → эксперимент → проверка результата. Это checkpoints работы, а не автоматическое присвоение навыка.
- **Библиотека** — 1703 записи с поиском, категориями, связями с темами и происхождением. Основной материал, другое объяснение, углубление и справочник показываются в карточке темы. Не нужно читать книги целиком.
- **Проекты** — 12 этапов Vulkan Renderer, от инициализации и uploads до PBR, culling, render graph, compute и GPU-driven. Каждый этап связан с темами и хранит описание проверенного результата. Современные техники выбираются по интересу.

Направления: математика; Vulkan; graphics pipeline; shaders; геометрия и структуры; свет и материалы; тени; текстуры и цвет; ray tracing; GI; post-processing; GPU/performance; renderer architecture; animation/advanced; инструменты.

Карточка содержит объяснение, применение, prerequisites, материалы, эксперимент, критерий завершения, самопроверку, подсказку, продолжения, заметки и статус. Например, [BVH](index.html#topic=bvh) и [GGX](index.html#topic=ggx) — самостоятельные темы; PBRT — источник.

Полный текст: **[ROADMAP.md](ROADMAP.md)**. Указатель тем: **[topics.html](topics.html)**. Разбор исходного состояния, решений и ограничений: **[docs/audit.md](docs/audit.md)**.

## Прогресс и прежний контент

Статусы: «Не изучал», «Знаком / нужна практика», «Изучаю», «Освоил», «Повторить позже». Знакомые и освоенные темы снимаются с обязательного маршрута. Практическое подтверждение хранится отдельно и требует описанного результата; оценка самостоятельная.

Все 245 прежних уроков, их ID, заметки, 8 проектов и старая полка сохранены. Программа доступна в **«Ещё → Архив прежней программы»**; текст — **[LEGACY-ROADMAP.md](LEGACY-ROADMAP.md)**. Это архив для обращения к прежним заданиям, а не вторая активная программа. Только три точно соответствующих старых упражнения могут подтвердить отдельные новые темы; широкие flags не выдают новые навыки автоматически.

Прогресс остаётся в `localStorage` с прежними keys. Экспорт **v9** содержит старые данные и `learning.knowledge`. Импорт **v6–v9** объединяет записи и сохраняет новые темы при загрузке старого файла. Пользуйся «Ещё → Экспорт прогресса» для переноса на другое устройство или URL. Доступность хранения для `file://` зависит от браузера; автоматической синхронизации нет.

## Источники и точность

Из [docs/likns.md](docs/likns.md) обработано 1701 перечисление. После объединения повторов и добавления прежних книг: 720 записей по графике, 630 по инженерной базе, 299 в дополнительном архиве, 54 служебные. Аудио, английский и другие материалы сохранены, но не включаются в основной маршрут. Служебные URL не открываются из библиотеки.

У 223 источников есть тематические связи; часть получена по названию алгоритма и требует проверки. Большинство назначений чтения пока указывают тему поиска, а не подтверждённый номер главы. Для проверенных разделов PBRT, Book of Shaders и Khronos есть отдельная пометка. Полного обхода всех URL не было. Источники без URL и отсутствующие локальные файлы перечислены с указанием ограничения.

## Разработка

```sh
npm ci
npm run sources
npm test
npm run test:browser
npm run docs
```

В Windows PowerShell при запрете `.ps1` используй `npm.cmd`. Браузерные проверки используют установленный Chrome; `BROWSER_CHANNEL=msedge` переключает на Edge.

- `data/knowledge.js` — темы, иерархия, graph links, задания, цели и этапы renderer.
- `knowledge-core.js` — graph traversal, маршрут и очистка нового прогресса без DOM.
- `data/references.js` — основные источники и точность чтения.
- `scripts/import-sources.mjs` → `data/source-catalogue.js` — воспроизводимый импорт заметок, дедупликация и предварительные связи.
- `app-knowledge.js`, `knowledge.css` — новый интерфейс; сохранённый engine обслуживает архив и совместимость.
- `data/legacy-curriculum.js`, `data/curriculum.js`, `data/roadmap.js`, `data/projects.js` — прежний контент со стабильными ID.
- `scripts/export-roadmap.mjs` — актуальный Markdown; `scripts/export-legacy-roadmap.mjs` — архив.

`npm test` проверяет DAG, независимость тем, маршрут, migration, provenance и сохранность прежнего контента. `npm run test:browser` проверяет новый интерфейс и архив, проектную rubric, заметки, import/export, мобильную ширину, `file://` и HTTP под `/graphics-road/`. Снимки проверки сохраняются в `test-results/`.

Для GitHub Pages публикуй HTML, CSS, JS и `data/` с относительными путями. Новых runtime dependencies нет.
