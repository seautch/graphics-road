# Graphics Programmer Roadmap — графика по порядку

Открой **[index.html](index.html)**. Сервер, сборка и установка зависимостей для самого сайта не нужны. Для GitHub Pages публикуй весь репозиторий вместе с `data/`, JS и CSS.

## С чего начинать

На стартовом экране нажми **«Начать учиться»**. Начало маршрута — язык C++, сборка и отладчик. При возвращении сайт предлагает продолжить текущий доступный блок. Каждый урок содержит конкретное чтение, эксперимент и критерий проверки.

Основной путь состоит из 11 предметных этапов:

1. **C++:** язык, отладчик, владение и контейнеры.
2. **Математика:** векторы, матрицы, геометрия, ориентации, анализ и вероятность.
3. **Конвейер и шейдеры:** CPU растеризатор, функции и процедурные изображения.
4. **Графический API:** один backend, синхронизация, память, shader toolchain, диагностика.
5. **Геометрия и сцена:** растеризация, глубина, камера, glTF и анимация.
6. **Текстуры, цвет и поверхность:** фильтрация, HDR, вывод цвета и normal mapping.
7. **GPU и compute:** параллельные алгоритмы, исполнение, память и измерения.
8. **Освещение:** источники, радиометрия, BRDF/PBR, тени, IBL, clustered lighting.
9. **Обработка изображения:** прозрачность, bloom, motion vectors и TAA.
10. **Инженерия рендерера:** visibility, LOD, CPU jobs, streaming, render graph.
11. **Законченный проект:** инструменты, тестирование, релиз, технический разбор и интервью.

Дерево показывает этот порядок центральным стволом; боковые ветви открывают блоки каждой темы. Есть масштабирование и переход к текущему шагу. В «Программе» доступны поиск и категории: основной путь, углубления, дополнительная практика.

По умолчанию используется D3D12. До этапа API этот выбор не влияет на занятия. Vulkan выбирается в раскрывающейся настройке маршрута. Второй API не требуется. Ray tracing, GI, screen-space, объёмный свет и Unreal — углубления после основы.

Проекты, проверка готовности, главы, короткие занятия и управление прогрессом находятся в меню **«Ещё»**. Все прежние ресурсы сохранены на «Полке», все 233 урока v7 сохранены со стабильными ID; добавлены 12 уроков по основам и источникам света. Всего: 52 блока, 245 уроков, 8 проектов. Основной путь с одним API — 32 блока.

Полный текст программы и заданий: **[ROADMAP.md](ROADMAP.md)**.

## Сохранения

Прогресс хранится в `localStorage` браузера. Экспорт v8 содержит отметки уроков, заметки, проекты, выбранный API и испытания. Импорт старых v6/v7 JSON поддерживается. При переносе урока в другую тему его ID, отметки и заметки сохраняются. Смена структуры не выдаёт автоматически новые навыки: старые подтверждения испытаний сохраняют описание результата, но требуют повторной проверки по новой рубрике.

Перед обновлением или сменой браузера сохрани JSON через «Ещё → Экспорт прогресса». На другом URL или устройстве импортируй его. Для `file://` доступность локального хранения зависит от браузера.

## Разработка

```sh
npm ci
npm test
npm run test:browser
npm run docs
```

В Windows PowerShell при запрете запуска `.ps1` используй `npm.cmd`. Браузерные проверки используют установленный Chrome; `BROWSER_CHANNEL=msedge` переключает на Edge.

- `data/legacy-curriculum.js`, `data/curriculum.js` — сохранённые исходные уроки и ресурсы.
- `data/roadmap.js` — предметная структура, порядок, переносы уроков и вводные занятия.
- `data/projects.js` — технические задания и критерии проектов.
- `app-roadmap.js`, `roadmap.css` — новый интерфейс и дерево с SVG-связями.
- `app-v7.js`, `roadmap-v7.css`, встроенный код `index.html` — совместимый движок уроков, библиотеки и сохранений.
- `scripts/export-roadmap.mjs` — генерация Markdown из тех же данных.

Проверки охватывают порядок предпосылок для обоих API, целостность всех прежних источников и уроков, разделение тем, навигацию, дерево, сохранения, импорт/экспорт и мобильную версию.
