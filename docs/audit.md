# Аудит и реализация v9

Задание: [target.md](target.md). Исходный каталог: [likns.md](likns.md). Аудит выполнен 27.10.2026.

## Что было

- Статический сайт без сборки: встроенный v6 engine в `index.html`, расширение `app-v7.js`, затем переопределения в `app-roadmap.js`.
- 52 модуля, 245 уроков, 8 проектов, 7 входных испытаний; отдельная старая карта из 57 nodes. ID уроков используются как keys сохранений.
- Дерево фактически показывало линейную программу из 11 этапов. В `data/roadmap.js` были зависимости `animation → sampling`, `compute-lab → gpu-hardware → light`, `temporal-lab → visibility`. Эти ограничения отражали порядок программы, а не техническую необходимость.
- Данные учебного контента достаточно содержательны: конкретные вопросы, задания и acceptance criteria. Их полная замена потеряла бы полезную практику и совместимость.
- `localStorage`: `graphics-roadmap-learning-v4` с lessons/read/notes, placement, projects и выбранным API; старые graph/resource keys хранятся отдельно. Миграция v8 уже отзывала несовместимые certificates, сохраняя evidence.
- Начало маршрута было C++, API по умолчанию D3D12, названия старых проектов и вводный уровень не соответствовали новому заданию.
- `topics.html` и ROADMAP.md показывали тот же линейный порядок. Названия экранов «Старт / Программа / Дерево / Сегодня / Полка / Главы» затрудняли выбор.

## Новая модель

- `data/knowledge.js`: 207 самостоятельных тем в 15 направлениях. Иерархия direction/group не создаёт зависимостей. Каждая тема имеет explanation, practice, criterion, self-check, hint, readings и prerequisite IDs. Для пространственных структур отдельно заданы применение, преимущества и ограничения.
- `knowledge-core.js`: проверка данных, транзитивные prerequisites, топологический маршрут к целям, доступность и учёт знакомых тем. Рекомендации и углубления не блокируют доступность.
- `data/references.js`: основной материал, альтернативное объяснение, справочник и углубление. Точная глава отмечается проверенной только при подтверждении по оглавлению; остальные bindings обозначены как поиск по теме.
- `data/source-catalogue.js`: генерируемый каталог из пользовательских заметок и прежних книг. `scripts/import-sources.mjs` сохраняет происхождение, aliases, упоминания без URL и недоступные локальные файлы; удаляет tracking-параметры, сохраняя anchors и значимые query values. Поиск по названию алгоритма создаёт предварительные тематические связи, а не подтверждённое назначение главы.
- `app-knowledge.js` и `knowledge.css`: основная карта, карточка, маршрут, одна текущая задача, библиотека с пагинацией и этапы Vulkan Renderer. Старая программа не используется для вычисления нового маршрута.

## Источники

Обработано 1701 исходное перечисление. После объединения повторов и добавления прежних книг — 1703 записи: 720 по графике, 630 по инженерной базе, 299 в дополнительном архиве, 54 служебные. 223 записи имеют конкретные тематические связи. Это классификация каталога, а не подтверждение качества или доступности каждого URL.

Категории экспорта не всегда точны: например, C++ High Performance находился в графике, а C++ By Example — среди локальных/служебных URL. Эти случаи исправлены правилами импорта. Сохранены аудио/DSP, английский, AI-инструменты, Blender, личные материалы и локальные файлы. Они не становятся обязательными шагами graphics route.

Проверены entry points Vulkan Guide, Khronos Synchronization Examples, PBRT 4e, The Book of Shaders, Scratchapixel, RTR, OSTEP, CSAPP, glTF, VMA, RGP и Advances. Для PBRT проверены конкретные названия разделов по оглавлению. RenderDoc запрещает автоматическое чтение; PMPP publisher вернул 403; часть сайтов недоступна инструменту. Их записи сохранены, главы не выдумываются. Полного обхода 1703 URL не проводилось.

## Сохранения

Новые поля находятся в `learning.knowledge`; старые keys, lesson IDs, notes, projects и marks остаются на месте. v9 экспорт включает оба поколения. Импорт v6/v7/v8 не стирает knowledge. Только три конкретных старых упражнения имеют точное соответствие новой теме; широкое подтверждение модуля не присваивает десятки новых навыков. Старые заметки читаются и экспортируются даже без такого соответствия.

«Знаком» позволяет обойти базу. «Освоил» — самооценка. Отдельное практическое подтверждение требует описанного результата; приложение не оценивает исходный C++ код. Статус «Повторить позже» возвращает тему в выбранный маршрут.

## Проверки

`npm test`: прежние гарантии сохранности контента плюс graph integrity, независимость направлений, вычисление маршрута, адаптация, migration, source provenance и deduplication.

`npm run test:browser`: Chrome, file:// и HTTP под `/graphics-road/`; карта, фильтры, source search, zoom/pan, темы, путь, доказательства, заметки, XSS escaping, v6/v7/v9 round-trip, архив, прежние projects и rubric, мобильная ширина 390 px и reset.

`npm run docs`: актуальный ROADMAP.md и архив LEGACY-ROADMAP.md из соответствующих данных.

## Оставшиеся ограничения

Большая часть каталога имеет только категоризацию. Даже автоматически найденные связи требуют редакторской проверки. Для большинства книг точный раздел назначения пока обозначен темой поиска, а не проверенным номером. Предыдущий engine сохранён для совместимости и архива; это осознанный технический долг. Карта использует DOM hierarchy и показывает связи через prerequisites и фокус на предшественниках; свободного редактирования графа и глобального полотна со всеми рёбрами нет. Сохранения локальные, синхронизации устройств нет.
